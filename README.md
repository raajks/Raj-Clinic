## 🚀 Technology Stack

- **Framework:** React 18 with TypeScript & Vite
- **Styling:** Tailwind CSS with custom medical theme tokens (Navy `#102A43`, Blue `#1769AA`, Teal `#12B8A6`, Emergency Red `#DC3545`)
- **3D Graphics:** Three.js, `@react-three/fiber`, and `@react-three/drei` with WebGL detection and seamless zero-overhead CSS/SVG fallback
- **Animations:** Framer Motion (Page reveals, accordions, lightboxes, respectful of `prefers-reduced-motion`)
- **Forms & Validation:** React Hook Form + Zod validation with automated WhatsApp enquiry message formatting
- **Icons:** Lucide React
- **SEO & Structured Data:** Semantic HTML5, Schema.org `MedicalClinic` JSON-LD, Open Graph tags, Twitter card, `sitemap.xml`, and `robots.txt`

## 💻 Local Development

```bash
# 1. Navigate to directory
cd Raj-Clinic-Website

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Create production build
npm run build

# 5. Preview production build
npm run preview
```

## 🔒 Patient Privacy & Medical Responsibility

- **Zero Fabricated Claims:** No fake testimonials, invented success percentages, or fabricated patient counts.
- **Transparent Booking:** Online forms clearly identify as **enquiry requests**, which are forwarded to WhatsApp for administrative scheduling.
- **Data Protection:** No sensitive patient health histories are requested or stored on public databases.
- **Comprehensive Disclaimers:** Visible medical disclaimers reinforce that website content is educational and does not replace in-person consultation with a qualified medical doctor.
